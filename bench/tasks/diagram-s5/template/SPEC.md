# diagram-s5 — Collaborative diagram editor (tier S5)

A draw.io/Excalidraw-class diagram editor: a framework-free core library, a collaboration server and a browser editor. Node.js 22 + browser, standard library only (no runtime npm dependencies).

## 1. Core library `src/core/index.js` (isomorphic ES module, no DOM)
`export function createDocument({ id, actor })` → `doc` with:
- **Model**: elements `{ id, type, x, y, width, height, rotation, style, text, layer, groupId, z }` for `type ∈ rect | ellipse | diamond | text | image | line`; connectors `{ id, type: "connector", source: {elementId, port?}, target: {...}, routing: "straight" | "orthogonal", waypoints[], label, style }`; layers `{ id, name, visible, locked, order }`; groups.
- **Operations**: `doc.apply(op)` for `add`, `update(id, patch)`, `remove(id)` (removing an element removes its connectors), `move(ids, dx, dy)`, `resize(id, box, {keepAspect})`, `rotate(id, deg)`, `group(ids)`, `ungroup(groupId)`, `reorder(id, "front"|"back"|"forward"|"backward")`, `addLayer/updateLayer/removeLayer`, `setStyle(ids, style)`. Locked layers reject edits (throw `DiagramError`).
- **History**: `doc.undo()`, `doc.redo()`, `doc.transaction(fn)` (one undo step), history limited to 500 steps; undo only reverts the local actor's operations.
- **Queries**: `doc.get(id)`, `doc.elements({layer, type})`, `doc.hitTest(x, y)` (topmost visible, rotation-aware), `doc.select(rect)` (fully contained), `doc.bounds(ids?)`.
- **Geometry**: `snap(point, {grid, guides})`; `align(ids, "left"|"center"|"right"|"top"|"middle"|"bottom")`; `distribute(ids, "horizontal"|"vertical")` (equal gaps).
- **Routing**: `doc.route(connectorId)` → polyline points. Orthogonal routes consist only of axis-parallel segments, start/end on the source/target boundaries, and do not pass through the interior of any other element (when a route exists inside the document bounds + 100 px margin).
- **Auto-layout**: `doc.layout("layered", {direction: "TB"|"LR", spacing})` for DAGs (Sugiyama-style: every edge points down/right, nodes in a layer don't overlap, crossing count no worse than the input order for the test graphs); `doc.layout("grid")`.
- **Serialization**: `doc.toJSON()` / `fromJSON(json)` (lossless round trip); `doc.toSVG({ padding })` — a valid standalone SVG with one element per shape/connector (`data-id` attributes) and escaped text; `importDrawio(xml)` — imports uncompressed draw.io (mxGraph) XML: vertices → shapes (rect/ellipse/rhombus→diamond), edges → connectors, labels, geometry.
- **Collaboration (CRDT)**: every op produced locally is available via `doc.on("op", cb)` and `doc.pendingOps()`; `doc.receive(remoteOps)` integrates ops from other replicas. Replicas that have received the same set of ops (in any order, with duplicates) converge to identical `toJSON()` output. Concurrent updates to different properties of one element both apply; concurrent updates to the same property resolve last-writer-wins by (Lamport clock, actor id); concurrent remove vs update → removed. z-order uses fractional indices.

## 2. Server `src/server.js`
`export function createServer({ dataDir })` → `http.Server` (not listening). Auth as in kanban-s3 (register/login/Bearer tokens). Documents: `POST /api/docs {title}`, `GET /api/docs`, `GET /api/docs/:id` (JSON snapshot), `DELETE`. Sharing: `POST /api/docs/:id/share {username, role: "editor"|"viewer"}`. Sync: `POST /api/docs/:id/ops {ops}` (editors) → `{ seq }`; `GET /api/docs/:id/ops?since=<seq>` → `{ ops, seq }` (long-poll up to 25 s with `wait=1`); WebSocket endpoint `/ws/docs/:id?token=` broadcasting ops and presence (`{type:"presence", actor, cursor, selection}`) — implemented on `node:http` upgrade without dependencies. Version history: `POST /api/docs/:id/versions {label}`, `GET .../versions`, `POST .../versions/:vid/restore`. Comments anchored to element ids with threads and resolve. Exports `GET /api/docs/:id/export.svg` and `.json`. Persistence: one file per document in `dataDir` plus an op log; restart-safe.

## 3. Editor UI (`GET /`, static under `/static/`)
Canvas/SVG editor with toolbar (shapes, text, connector tool), select/move/resize/rotate handles, multi-select (shift, marquee), snapping guides, keyboard shortcuts (Delete, Ctrl+Z/Y, Ctrl+C/V/D, arrows), property panel (fill, stroke, font, opacity), layers panel, zoom/pan (wheel, pinch), minimap, align/distribute buttons, auto-layout menu, import draw.io / export SVG & JSON, version history panel, comments sidebar, live collaborators' cursors and selections, offline edits queued and synced on reconnect.
