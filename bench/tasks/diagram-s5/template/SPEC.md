# diagram-s5 — Collaborative diagram editor (tier S5)

A draw.io/Excalidraw-class diagram editor: a framework-free core library, a collaboration server and a browser editor. Node.js 22 + browser, standard library only (no runtime npm dependencies).

## 1. Core library `src/core/index.js` (isomorphic ES module, no DOM)
Named exports: `createDocument`, `fromJSON`, `importDrawio`, `snap`, `DiagramError` (a subclass of `Error`).

`createDocument({ id, actor })` → `doc` (`doc.id`, `doc.actor` are readable) with:
- **Model**: elements `{ id, type, x, y, width, height, rotation, style, text, layer, groupId, z }` for `type ∈ rect | ellipse | diamond | text | image | line`; connectors `{ id, type: "connector", source: {elementId, port?}, target: {...}, routing: "straight" | "orthogonal", waypoints[], label, style }`; layers `{ id, name, visible, locked, order }`; groups.
- **Operations**: `doc.apply(op)` where `op` is one of these objects (unknown types / unknown ids → `DiagramError`):
  `{type:"add", element}` (element or connector object incl. `id` and `type`; missing numeric fields default to 0, `rotation` 0, `layer` = the default layer),
  `{type:"update", id, patch}` (shallow merge; `style` is merged key-by-key),
  `{type:"remove", id}` (removing an element also removes connectors attached to it),
  `{type:"move", ids, dx, dy}`, `{type:"resize", id, box:{x,y,width,height}, keepAspect?}`, `{type:"rotate", id, deg}` (sets `rotation` in degrees, about the element centre),
  `{type:"group", ids, groupId?}`, `{type:"ungroup", groupId}`, `{type:"reorder", id, to:"front"|"back"|"forward"|"backward"}`,
  `{type:"addLayer", layer:{id, name, visible?, locked?}}`, `{type:"updateLayer", id, patch}`, `{type:"removeLayer", id}`, `{type:"setStyle", ids, style}`.
  Any op that would create or modify an element on a locked layer throws `DiagramError`.
- **History**: `doc.undo()`, `doc.redo()`, `doc.transaction(fn)` (one undo step), history limited to 500 steps; undo only reverts the local actor's operations.
- **Queries**: `doc.get(id)` (element/connector object or `undefined`), `doc.elements({layer, type}?)` (all shapes and connectors, back-to-front), `doc.hitTest(x, y)` (topmost visible shape containing the point, rotation-aware, or `null`), `doc.select(rect)` (shapes fully contained), `doc.bounds(ids?)`.
- **Geometry**: exported `snap(point, {grid, guides})`; `doc.align(ids, "left"|"center"|"right"|"top"|"middle"|"bottom")` (to the extreme/centre of the selection's bounds); `doc.distribute(ids, "horizontal"|"vertical")` (keeps the two outermost shapes fixed and makes the gaps between consecutive shapes equal). Both are undoable.
- **Routing**: `doc.route(connectorId)` → polyline as an array of `[x, y]` points. Orthogonal routes consist only of axis-parallel segments, start/end on the source/target boundaries, and do not pass through the interior of any other element (when a route exists inside the document bounds + 100 px margin).
- **Auto-layout**: `doc.layout("layered", {direction: "TB"|"LR", spacing})` for DAGs (Sugiyama-style: every edge points down/right, nodes in a layer don't overlap, crossing count no worse than the input order for the test graphs); `doc.layout("grid")`.
- **Serialization**: `doc.toJSON()` / `fromJSON(json)` (lossless round trip); `doc.toSVG({ padding })` — a valid standalone SVG with one element per shape/connector (`data-id` attributes) and escaped text; `importDrawio(xml)` — imports uncompressed draw.io (mxGraph) XML: vertices → shapes (rect/ellipse/rhombus→diamond), edges → connectors, labels, geometry.
- **Collaboration (CRDT)**: ops produced locally (including by undo/redo) are emitted via `doc.on("op", cb)` and buffered; `doc.pendingOps()` returns the serializable local ops produced since the previous `pendingOps()` call and clears that buffer (received ops are never included). `doc.receive(remoteOps)` integrates ops from other replicas and is idempotent (duplicates are ignored). Replicas that have received the same set of ops (in any order, with duplicates) converge to identical `toJSON()` output. Concurrent updates to different properties of one element both apply; concurrent updates to the same property resolve last-writer-wins by (Lamport clock, actor id); concurrent remove vs update → removed. z-order uses fractional indices.

## 2. Server `src/server.js`
`export function createServer({ dataDir })` → `http.Server` (not listening). JSON bodies; errors `{error, message}` with 400/401/403/404/409. Auth: `POST /api/auth/register {username, password}` → 201 `{user}`; `POST /api/auth/login` → `{token, user}`; `Authorization: Bearer <token>` on all other `/api` routes. Documents: `POST /api/docs {title}` → 201 `{id, title, ...}`, `GET /api/docs`, `GET /api/docs/:id` (the document's `toJSON()` snapshot plus metadata), `DELETE`. Sharing: `POST /api/docs/:id/share {username, role: "editor"|"viewer"}`. Sync: `POST /api/docs/:id/ops {ops}` (editors) → 200 `{ seq }`; `GET /api/docs/:id/ops?since=<seq>` → `{ ops, seq }` (long-poll up to 25 s with `wait=1`); WebSocket endpoint `/ws/docs/:id?token=` broadcasting ops and presence (`{type:"presence", actor, cursor, selection}`) — implemented on `node:http` upgrade without dependencies. Version history: `POST /api/docs/:id/versions {label}`, `GET .../versions`, `POST .../versions/:vid/restore`. Comments anchored to element ids with threads and resolve. Exports `GET /api/docs/:id/export.svg` and `.json`. Persistence: one file per document in `dataDir` plus an op log; restart-safe.

## 3. Editor UI (`GET /`, static under `/static/`)
Canvas/SVG editor with toolbar (shapes, text, connector tool), select/move/resize/rotate handles, multi-select (shift, marquee), snapping guides, keyboard shortcuts (Delete, Ctrl+Z/Y, Ctrl+C/V/D, arrows), property panel (fill, stroke, font, opacity), layers panel, zoom/pan (wheel, pinch), minimap, align/distribute buttons, auto-layout menu, import draw.io / export SVG & JSON, version history panel, comments sidebar, live collaborators' cursors and selections, offline edits queued and synced on reconnect.
